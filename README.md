# 30 Ngày Camunda 8

> Học Camunda 8 mỗi ngày một kiến thức — Java · Spring Boot · Self-managed

## Stack

- **Camunda 8.9** (Self-managed)
- **Java 21** + **Spring Boot 3.x**
- **Docker Compose** để chạy local

## Setup nhanh

```bash
# 1. Clone repo
git clone https://github.com/YOUR_USERNAME/camunda-30days
cd camunda-30days

# 2. Xem docs local
npm install
npm start
# → http://localhost:3000
```
