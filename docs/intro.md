# 30 Ngày Camunda 8

Mỗi ngày một kiến thức về **Camunda 8** với **Java + Spring Boot + Self-managed**.

## Stack sử dụng

| Thành phần | Version |
|---|---|
| Camunda | 8.9.x |
| Java | 21 |
| Spring Boot | 3.x |
| Docker Compose | v2 |
